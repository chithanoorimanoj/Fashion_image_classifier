# Fashion Product Image Classification

## Project Overview
Developed a Machine Learning-based image classification system to classify fashion products into 10 different categories, including T-shirts, Shirts, Shoes, Watches, Kurtas, Handbags, and more.

The project uses image preprocessing, feature extraction, and classification algorithms to identify fashion product categories.

## Technologies Used
- Python
- Pandas & NumPy
- Matplotlib
- Scikit-learn
- Pillow (PIL)
- Joblib

## Key Features
- Worked with 44K+ fashion product records.
- Image preprocessing and image-data matching.
- Implemented Linear SVM and Random Forest classifiers.
- Model evaluation using accuracy, classification reports, and confusion matrices.
- Achieved **88.9% accuracy using Random Forest**.
- Saved the trained model using Joblib for deployment.

## Machine Learning Models
- Linear Support Vector Machine (SVM)
- Random Forest Classifier

## Project Workflow
1. Dataset collection and exploration.
2. Data preprocessing and cleaning.
3. Image-data matching.
4. Feature extraction.
5. Model training and evaluation.
6. Model serialization using Joblib.
